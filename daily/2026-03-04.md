- 历史记录可全局查看，不限于单一产线

**验收标准**:

### T4: 实现能力指数仪表盘展示

**目标**: 可视化展示能力分析结果

**功能需求**:

- 每个指数显示:
  - 数值
  - 评价等级（颜色标识）
  - 评价文字
- 分布直方图
- 数据分布图
- 正态性检验结果展示
- 数据统计信息
- 能力评价总结

**执行步骤**:
1. 创建 `src/views/CapabilityDashboard.vue` 或 `src/components/capability/CapabilityDashboard.vue`
2. 创建指数卡片组件 (使用 el-card)
3. 使用 ECharts 绘制直方图和分布图
4. 实现颜色映射（红/黄/蓝/绿）:
   - 红色: 能力不足 (Cpk < 1.0)
   - 黄色: 能力一般 (1.0 ≤ Cpk < 1.33)
   - 蓝色: 能力充足 (1.33 ≤ Cpk < 1.67)
   - 绿色: 能力优秀 (Cpk ≥ 1.67)
5. 连接后端 API 数据

**ECharts配置参考**:
- 直方图: 使用 bar 系列 + 自定义bin计算
- 正态分布曲线: 使用 line 系列 + 正态分布函数

**验收标准**:
- 所有能力指数正确显示
- 图表正常渲染
- 颜色与等级对应正确
- 响应式布局
