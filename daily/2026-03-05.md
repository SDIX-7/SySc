### T2: 创建测试数据（产线和测量数据）

**目标**: 准备测试数据用于能力分析功能测试

**执行步骤**:
1. 通过API创建测试产线
2. 创建足够的测量数据（建议至少50个数据点）
3. 验证数据是否正确保存
4. 准备正态分布和非正态分布的测试数据

**数据准备建议**:
- 产线1: 正态分布数据，Cpk ≈ 1.5（能力充足）
- 产线2: 正态分布数据，Cpk ≈ 0.8（能力不足）
- 产线3: 非正态分布数据

**验收标准**:
- 测试数据创建成功
- 数据可以通过API正常查询
- 数据质量良好

### T3: 端到端测试：新建能力分析流程

**目标**: 测试从创建分析到查看结果的完整流程

**测试用例**:
1. **从产线导入数据**:
   - 选择产线
   - 输入规格限（USL, LSL）
   - 选择"从产线导入"
   - 选择数据范围（最近50条）
   - 点击导入数据
   - 验证数据预览
   - 点击"开始分析"
   - 验证跳转至详情页

2. **手动输入数据**:
   - 选择产线
   - 输入规格限
   - 选择"手动输入"
   - 输入测试数据
   - 点击"解析数据"
   - 验证数据预览
   - 点击"开始分析"

3. **文件上传**:
   - 准备测试CSV/Excel文件
   - 选择产线
   - 输入规格限
   - 选择"文件上传"
   - 上传文件
   - 验证数据解析
   - 点击"开始分析"

4. **边界情况**:
   - USL ≤ LSL（验证错误提示）
   - 数据少于2个（验证错误提示）
   - 不输入分析名称（验证使用默认名称）

**验收标准**:
- 所有测试用例正常执行
- 错误提示清晰准确
- 分析结果正确展示
