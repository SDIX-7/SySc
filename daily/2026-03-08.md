### T1: 研究MSA/GR&amp;R标准和计算方法

**目标**: 深入理解MSA和GR&amp;R的标准和计算方法

**研究内容**:

1. **MSA (测量系统分析) 概述**:
   - 测量系统的组成：量具、操作员、零件、方法、环境
   - 测量系统变异的来源：重复性、再现性、偏倚、稳定性、线性

2. **GR&amp;R (量具重复性和再现性)**:
   - **重复性 (Repeatability)**: 同一操作员用同一量具对同一零件多次测量的变异
   - **再现性 (Reproducibility)**: 不同操作员用同一量具对同一零件测量的变异
   - **GR&amp;R = 重复性 + 再现性**

3. **GR&amp;R计算方法**:
   - **X-R方法** (AIAG推荐，先实现)
   - **ANOVA方法** (可选，后续实现)

4. **GR&amp;R判定标准** (AIAG标准):
   - %GR&amp;R &lt; 10%: 可接受 ✓
   - 10% ≤ %GR&amp;R &lt; 30%: 条件接受（取决于应用）
   - %GR&amp;R ≥ 30%: 不可接受 ✗

5. **NDC (可分辨类别数)**:
   - NDC = 1.41 × (σ_part / σ_grr)
   - NDC ≥ 5: 可接受 ✓

6. **GR&amp;R研究设计**:
   - 零件数量：通常10个零件
   - 操作员数量：通常2-3个操作员
   - 重复次数：通常2-3次重复测量
   - 测量顺序：随机化

**参考资料**:
- AIAG MSA手册（第4版）
- AIAG-VDA SPC Yellow Volume 2026

### T6: 实现GR&amp;R计算引擎（X-R方法）

**目标**: 实现完整的GR&amp;R计算引擎（先实现X-R方法）

**计算内容（基于AIAG X-R方法）**:

**1. 数据准备**:
   - 检查数据完整性
   - 验证零件数量、操作员数量、重复次数
   - 按零件、操作员、试验次数组织数据

**2. 极差计算**:
   - 每个操作员-零件组合的极差 (R_ij)
   - 操作员极差均值 (R_operator = 平均R_ij)
   - 总极差均值 (R_bar = 平均所有R_ij)
   - 零件均值 (X_part = 平均同一零件的所有测量)
   - 操作员均值 (X_operator = 平均同一操作员的所有测量)
   - 总体均值 (X_double_bar = 平均所有测量)

**3. 控制图常数** (d2, d2', D3, D4, A2):
   - 基于重复次数(n)查找常数
   - n=2: d2=1.128, D3=0, D4=3.267, A2=1.880
   - n=3: d2=1.693, D3=0, D4=2.574, A2=1.023

**4. 方差分量计算**:
   - **重复性方差** (σ²_e) = (R_bar / d2)²
   - **再现性方差** (σ²_o) = max(0, (X_diff_bar / d2')² - σ²_e / n)
     - X_diff_bar = 操作员均值的极差
     - d2' = 基于操作员数量(o)的常数
   - **GR&amp;R方差** (σ²_grr) = σ²_e + σ²_o
   - **零件方差** (σ²_p) = max(0, (R_p / d2)² - σ²_grr / (n×o))
     - R_p = 零件均值的极差
     - d2 = 基于零件数量(p)的常数
   - **总方差** (σ²_total) = σ²_grr + σ²_p

**5. GR&amp;R指标计算**:
   - %GR&amp;R = (σ_grr / σ_total) × 100
   - NDC (可分辨类别数) = 1.41 × (σ_p / σ_grr)
   - %P/T = (6 × σ_grr / Tolerance) × 100 (如果有公差)

**6. 结果判定**:
   - %GR&amp;R &lt; 10%: 可接受 ✓
   - 10% ≤ %GR&amp;R &lt; 30%: 条件接受（取决于应用）
   - %GR&amp;R ≥ 30%: 不可接受 ✗
   - NDC ≥ 5: 可接受 ✓
