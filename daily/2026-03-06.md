### T6: 设计OCAP数据模型

**目标**: 设计失控行动计划（OCAP）数据模型

**OCAP概述**:
OCAP (Out-of-Control Action Plan) 是当过程失控时应采取的标准化行动步骤。根据最佳实践，OCAP应包含：
1. **信号识别与优先级** - 识别SPC信号类型并确定优先级
2. **即时遏制与隔离** - 0-60分钟、1-24小时、24-72小时的行动计划
3. **根本原因分析** - 5 Whys、鱼骨图、帕累托分析
4. **纠正措施实施与验证** - 行动步骤、责任人、验证

**设计要点**:
1. OCAP与控制图配置关联
2. 支持SPC信号类型分类（点超出控制限、连续9点、趋势等）
3. 支持优先级评估（严重性、范围、趋势可能性）
4. 支持多阶段行动（遏制、调查、纠正、验证）
5. 支持根本原因分析工具
6. 支持状态跟踪和证据收集

**建议的模型字段** (基于OCAP最佳实践):

**OCAP (失控行动计划主表)**:
```python
- id (主键)
- control_chart_config_id (外键 -> ControlChartConfig)
- name (OCAP名称)
- description (描述)
- signal_type (信号类型: point_beyond_3sigma/run_9/trend_6/zone_2of3/etc)
- priority (优先级: critical/high/medium/low)
- severity_score (严重性评分 1-10)
- scope_score (范围评分 1-10)
- trend_score (趋势评分 1-10)
- overall_priority_score (综合优先级评分)
- status (状态: draft/active/executing/completed/closed)
- is_active (是否激活)

- updated_at (更新时间)
```
